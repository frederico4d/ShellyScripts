# PrecoCoopernico.js 
Consulta os valores da energia indexada OMIE, aplica a formula da [Coopérnico](https://coopernico.org/) para ter o preço da eletricidade por quarto de hora actualizado e muda o led do Plug conforme o preço:
com as cores:
CYAN: 0.1€ 
GREEN: 0.2€
ORANGE: 0.3€
RED: 0.4€
